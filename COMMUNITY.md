# Kite 社区入口 / Community Hub

[中文](#中文) | [English](#english)

## 中文

欢迎使用、讨论和共建 Kite。请选择与当前目的相符的入口：

| 你的目的 | 入口 | 需要提供 |
| --- | --- | --- |
| 随便交流、分享体验或兼容性观察 | [General](https://github.com/Yokin-XY/Kite/discussions/categories/general) | 话题、背景、希望获得的反馈 |
| 提出尚未形成开发任务的功能想法 | [Ideas](https://github.com/Yokin-XY/Kite/discussions/categories/ideas) | 消费场景、期望效果；实现想法可选 |
| 询问安装、使用或配置问题 | [Q&A](https://github.com/Yokin-XY/Kite/discussions/categories/q-a) | 问题、背景、已经尝试的方式和必要环境 |
| 报告可以复现的软件缺陷 | [Bug Report](https://github.com/Yokin-XY/Kite/issues/new?template=bug_report.yml) | 当前表现、预期表现、复现步骤、环境和证据 |
| 查看或认领当前任务 | [近期任务 #10](https://github.com/Yokin-XY/Kite/issues/10) | 认领编号和简要计划 |
| 准备亲自提交代码、文档、测试或设计 | [代码贡献方向](https://github.com/Yokin-XY/Kite/issues/new?template=contribution.yml) | 消费场景、效果、机制、范围、风险和验证计划 |
| 私密报告安全漏洞 | [Security Advisories](https://github.com/Yokin-XY/Kite/security/advisories/new) | 影响、复现、攻击条件和建议修复；不要公开凭据或漏洞细节 |

普通用户不需要理解代码机制。准备亲自实现的人必须在写代码前说明机制，并通过 Pull Request 接受正式审查。完整规则见 [参与开发](CONTRIBUTING.md)、[社区治理](GOVERNANCE.md)、[支持政策](SUPPORT.md)、[安全政策](SECURITY.md)和[社区行为规范](CODE_OF_CONDUCT.md)。

## English

Welcome to the Kite community. Choose the surface that matches your goal:

| Goal | Entry | What to provide |
| --- | --- | --- |
| General conversation, experience, or compatibility observations | [General](https://github.com/Yokin-XY/Kite/discussions/categories/general) | Topic, context, and desired feedback |
| A feature idea that is not yet an implementation task | [Ideas](https://github.com/Yokin-XY/Kite/discussions/categories/ideas) | Use case and desired outcome; mechanism is optional |
| Installation, usage, or configuration help | [Q&A](https://github.com/Yokin-XY/Kite/discussions/categories/q-a) | Question, context, attempts, and relevant environment |
| A reproducible software defect | [Bug Report](https://github.com/Yokin-XY/Kite/issues/new?template=bug_report.yml) | Current and expected behavior, reproduction, environment, and evidence |
| Browse or claim current work | [Current tasks #10](https://github.com/Yokin-XY/Kite/issues/10) | Task number and a short plan |
| Implement code, documentation, tests, or design | [Code contribution proposal](https://github.com/Yokin-XY/Kite/issues/new?template=contribution.yml) | Use case, outcome, mechanism, scope, risk, and verification plan |
| Privately report a vulnerability | [Security Advisories](https://github.com/Yokin-XY/Kite/security/advisories/new) | Impact, reproduction, attack conditions, and possible fix; never disclose credentials publicly |

Ordinary users do not need to understand the code mechanism. People who plan to implement a change must disclose the mechanism before coding and complete formal Pull Request review. See [Contributing](CONTRIBUTING.en.md), [Governance](GOVERNANCE.md#english), [Support](SUPPORT.md#english), [Security](SECURITY.md#english), and the [Code of Conduct](CODE_OF_CONDUCT.md#english).
