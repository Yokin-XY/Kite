# 能力状态

本表用于区分正式版本承诺和仍在研究的入口。代码存在不等于能力已经进入稳定支持范围。

## 稳定能力

| 能力 | 当前边界 |
| --- | --- |
| 首页卡片与 Recipe | 支持有序步骤、运行实例、通知、重置和关闭 |
| 资源中心 | 支持依赖计划、受管安装、验证、登记、打开和卸载 |
| 终端与 SH 报告 | 支持交互终端、后台报告、独立窗口和实例回收 |
| WebView 工作台 | 支持本地/普通网页、前进后退、刷新及显示生命周期 |
| 系统浏览器认证桥 | 支持 OAuth/SSO handoff、应用回调和 CLI loopback relay |
| 运行管理 | 按实例拓扑显示卡片、终端和进程，并提交统一关闭动作 |
| Android 运行底座 | 支持 Ubuntu PRoot、工具链、共享目录、通知和启动诊断 |

## 实验能力

| 能力 | 当前提示 |
| --- | --- |
| 浏览器自动化 | 基于 WebView 的观察和动作接口；不承担账号授权，不保证所有网页兼容 |
| X11 桌面 | 原生 X11 显示与实验资源仍保留；交互、兼容和生命周期尚未形成正式验收闭环 |

实验能力不得写入正式发布完成清单。稳定功能不能依赖实验模式才能工作。

## 未承诺能力

- Kite 不是通用桌面浏览器，也没有嵌入完整 Chromium 浏览器产品。
- Kite 不绕过 Provider 的账号、地区、风控或多因素认证要求。
- Kite 不保证第三方安装源始终可用；资源安装必须把网络和验证失败明确反馈给用户。
- Kite 不提供强进程隔离容器；实例容器用于归属、管理和回收，底层仍共享现有 Ubuntu/PRoot 运行环境。
