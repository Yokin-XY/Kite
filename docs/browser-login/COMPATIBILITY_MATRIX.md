## 状态说明

- `verified`：已有 OnePlus 8T 设备证据。
- `verified_account_gate`：真实站点/CLI 已跑到账号授权前或账号页，已有设备证据；完整授权仍需用户账号或外部凭据。
- `verified_by_policy`：已有分类器/策略测试证明该场景不受 OAuth handoff 影响；后续可补设备截图。
- `implemented_unverified`：Kite 已有通用机制覆盖，但还缺真实站点/账号/CLI 验证。
- `blocked_by_account_or_cli`：需要用户账号、CLI 环境或真实 provider callback 才能继续确认。
- `not_supported_as_primary`：不作为默认正式路线。

账号验证不强制绑定 Google、验证码或 MFA 场景。通用节点见 `ACCOUNT_VERIFICATION_NODES.md`：N1/N2/N3 证明浏览器环境与回跳入口，N4/N5 才证明具体账号已完成登录。人工账号验证前的高置信度测试方法见 `LOGIN_TEST_STRATEGY.md`。
