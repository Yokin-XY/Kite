## T001 [P0] 建立字段语义与链路回归安全网

- 问题证据：
  - `AgentModelLibraryStore.kt` 以 Provider 偏好保存 `modelDisplayNames`，但调用方对自定义来源使用原生短模型 ID，对官方来源使用合成 Provider ID，现有策略未覆盖免费/官方别名。
  - `AgentModelLibraryPolicy.kt` 的官方来源 ID 为 `__kite_official__:<accountId>`，会话过滤却按 `AgentConfigChoice.groupId` 查询可见性，两个身份空间没有统一映射。
  - `AgentDraftModelPolicy.kt` 对持久 Provider 应用显示别名，但对协议发现的免费/官方 choices 原样复制名称。
- 解法：先用策略与存储单测固定“别名只改 name，不改 value/model ID”“系统来源可见性按稳定来源映射”“草稿/恢复继续携带真实模型引用”。
- 验收标准：
  - [x] 免费、官方、自定义来源均有别名存储/现有投影安全网。
  - [x] 可见性过滤保留当前模型的既有安全网通过。
  - [x] 默认选择、草稿选择和实际 `setConfiguration` 映射仍使用真实值。
  - [x] 目标 JVM 测试通过。
- 依赖：无。
