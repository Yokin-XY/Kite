# Kite 支持政策 / Support Policy

[中文](#中文) | [English](#english)

## 中文

### 从哪里获得帮助

- 安装、使用、配置和行为理解：进入 [Q&A](https://github.com/Yokin-XY/Kite/discussions/categories/q-a)。
- 开放交流和经验分享：进入 [General](https://github.com/Yokin-XY/Kite/discussions/categories/general)。
- 新功能想法：进入 [Ideas](https://github.com/Yokin-XY/Kite/discussions/categories/ideas)。
- 可以稳定复现的软件缺陷：提交 [Bug Report](https://github.com/Yokin-XY/Kite/issues/new?template=bug_report.yml)。
- 涉及凭据泄露、权限绕过、远程执行或供应链攻击的漏洞：按照 [安全政策](SECURITY.md)私密报告，不要创建公开 Issue。

请提供足以理解问题的 Kite 版本、Android 版本、设备、相关 Agent 或资源版本、操作步骤和已经尝试的方法。提交日志或截图前必须移除 Token、API Key、账号、私人路径标识和其他敏感数据。

社区维护按可用时间提供帮助，不承诺固定响应时间、兼容所有第三方环境或为实验能力提供长期支持。Latest Release 是正式版本，`main` 是开发主线；是否属于稳定支持范围以 [能力状态](docs/reference/feature-status.md) 为准。

## English

### Where to get help

- Installation, usage, configuration, and behavior questions: use [Q&A](https://github.com/Yokin-XY/Kite/discussions/categories/q-a).
- Open conversation and experience sharing: use [General](https://github.com/Yokin-XY/Kite/discussions/categories/general).
- New feature ideas: use [Ideas](https://github.com/Yokin-XY/Kite/discussions/categories/ideas).
- Reproducible software defects: submit a [Bug Report](https://github.com/Yokin-XY/Kite/issues/new?template=bug_report.yml).
- Credential exposure, permission bypass, remote execution, or supply-chain vulnerabilities: follow the [Security Policy](SECURITY.md#english) and do not open a public Issue.

Include the Kite version, Android version, device, relevant Agent or resource versions, steps, and previous attempts needed to understand the problem. Remove tokens, API keys, account data, private path identifiers, and other sensitive information before sharing logs or screenshots.

Community support is provided as maintainer time permits. The project does not guarantee a response time, compatibility with every third-party environment, or long-term support for experimental capabilities. Latest Release is the formal release line and `main` is the development line; [Feature Status](docs/reference/feature-status.md) defines the supported scope.
